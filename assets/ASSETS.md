# Netflix Analytics Assets

All supplied Netflix Analytics visual assets are organized here.

- `hero/` — dashboard hero/banner image
- `branding/` — Netflix Analytics logo
- `backgrounds/` — cinema background
- `icons/` — navigation, KPI, filter, search, trends, TV-show and other UI icons
- `posters/` — movie/TV thumbnails and featured posters
- `kpi/` — KPI artwork
